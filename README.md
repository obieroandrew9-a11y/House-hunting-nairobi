# House-hunting-nairobi
Helping Nairobi residents look for a designated house for there living.
House Hunting Nairobi

About the Project

House Hunting Nairobi is a web application project designed to help people find houses for rent in Nairobi, Kenya. It aims to make the house-hunting process easier by allowing users to explore properties and compare housing options based on their needs and budget.

Project Goals

- Help users find suitable rental houses.
- Make it easier to compare properties.
- Display property prices, locations, bedrooms, and descriptions.
- Help users contact property owners or agents.
- Provide a simple, mobile-friendly experience.

Planned Features

- Search houses by location and price.
- Filter properties by number of bedrooms.
- View property descriptions and photos.
- Display rental prices in Kenyan shillings (KSh).
- Contact property owners or agents.
- Support mobile phones and desktop computers.

Technology

- HTML
- CSS
- JavaScript
- React
- Vite

Getting Started

Install Node.js on a computer, then clone this repository:

git clone https://github.com/obieroandrew9-a11y/House-hunting-nairobi.git
cd House-hunting-nairobi
npm install
npm run dev

Open the local URL provided by Vite to view the application.

Property Information

The application may display property information such as:

- Property title
- Location
- Monthly rent
- Number of bedrooms
- Property type
- Description
- Image URL
- Contact information

Actual property listings must be added and verified before the application can be used as a live listing service.

Project Status

This project is under development. Property search, listing management, and other features will be implemented progressively.

About the Project

House Hunting Nairobi is a web application designed to help people find rental houses and apartments in Nairobi, Kenya. The project aims to simplify the house-hunting process by allowing users to explore properties, compare rental options, and find accommodation that matches their needs and budget.

Project Goals

- Help users find suitable rental houses and apartments.
- Make it easier to compare properties and rental prices.
- Display property locations, prices, bedrooms, and descriptions.
- Help users contact property owners or agents.
- Provide a simple, responsive, mobile-friendly experience.

Planned Features

- Search properties by location and price.
- Filter listings by the number of bedrooms.
- View property descriptions and photographs.
- Display monthly rental prices in Kenyan shillings (KSh).
- Provide contact information for property owners or agents.
- Support mobile phones, tablets, and desktop computers.
- Allow users to explore available properties conveniently.

Technologies

The project uses the following technologies:

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Supabase (if configured for database and backend services)

Getting Started

Prerequisites

Install "Node.js" (https://nodejs.org/) and npm on your computer.

Installation

Clone the repository:

git clone https://github.com/obieroandrew9-a11y/House-hunting-nairobi.git

Open the project folder:

cd House-hunting-nairobi

Install the project dependencies:

npm install

Start the development server:

npm run dev

Open the local URL displayed in your terminal to view the application.

Building for Production

To create a production build, run:

npm run build

Vite will generate the production files in the "dist" directory.

Property Information

Property listings may include:

- Property title
- Location or neighbourhood
- Monthly rental price
- Number of bedrooms
- Property type
- Description
- Property photographs or image URLs
- Owner or agent contact information

Property information should be accurate and verified before listings are published. Users should confirm availability, pricing, ownership or agency details, and viewing arrangements before making payments.
